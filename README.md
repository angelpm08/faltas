# ControlFaltas SMR

Aplicación web para iPhone y ordenador con control de faltas, horario, calendario y simulaciones.

Los registros personales se guardan exclusivamente en el almacenamiento local del navegador/dispositivo y no se suben a este repositorio. Haz copias de seguridad desde los ajustes.

Para publicar, entra en Settings → Pages → Deploy from a branch → main → /(root) → Save. Después abre la URL de Pages desde Safari y selecciona Compartir → Añadir a pantalla de inicio.

La sincronización con GestIB no está incluida en esta versión móvil.
